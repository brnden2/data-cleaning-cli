\# Data Cleaning CLI



\## objective



Build a Python command-line program that cleans CSV data using small reusable functions.



\## cleaning Rules



The program will:



* Detect empty required values
* Detect duplicate rows
* Detect invalid values
* Keep valid rows
* \- Save cleaned data into a new CSV file



\## Input Cases



The program should handle:



* Normal input
* Empty input
* Invalid input



\## Week 2 Learning Goals



* Practice conditions
* Practice loops
* Write reusable functions
* Test functions
* Build a command-line interface



\## Planned Data Flow



CSV input

\-> Read each row

\-> Check Empty values

\-> Check invalid values

\-> Check duplicates

\-> Keep valid rows

\-> Save cleaned CSV output
